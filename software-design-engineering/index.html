Summary of Enhancements

The original implementation stored contacts in an ArrayList, requiring a linear scan for lookups and duplicate-ID checks. The enhanced version replaces this with a HashMap keyed by contact ID, reducing both operations to constant time. The enhancement also closes an empty-string validation gap that allowed blank contact fields to pass validation, and expands the JUnit test suite to cover both that gap and true boundary-value cases.
