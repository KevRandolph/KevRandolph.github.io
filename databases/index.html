Summary of Enhancements

The original CRUD module already passed database credentials in as parameters rather than hardcoding them, but the dashboard script that used it hardcoded credentials anyway. The enhanced version moves those credentials into environment variables, adds a custom exception so a failed database connection is raised clearly instead of silently returning empty results, replaces four fixed rescue-type filter presets with independently combinable filters for breed, sex, and age range, adds a MongoDB aggregation pipeline to produce grouped breed-count summaries, and changes the map callback to look up columns by name first instead of by fragile positional index.
