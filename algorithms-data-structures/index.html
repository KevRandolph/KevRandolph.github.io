Summary of Enhancements

The original implementation already tracked win history, rolling win rate, and loss internally during training, but this data was only ever printed to the console as text. The enhanced version adds visualization by plotting win rate and loss over the course of training, changes the game-playing function to report step count in addition to win/loss so training efficiency can be measured, and adds a comparison harness that trains the agent with two different exploration decay rates and plots the results side by side.
